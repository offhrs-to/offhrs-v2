## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Environment variables

For the landing page "Download your app" (App Store / Google Play) buttons, optionally set in `.env.local` or in your host (e.g. Vercel):

- `NEXT_PUBLIC_APP_STORE_URL` – App Store link (e.g. `https://apps.apple.com/app/...`)
- `NEXT_PUBLIC_PLAY_STORE_URL` – Google Play link (e.g. `https://play.google.com/store/apps/details?id=...`)

If unset, the buttons link to `#`. See `.env.example` for a template.
